# BIZONE Business Suite — Official Releases & Updates

This repository serves as the official distribution and update endpoint for **BIZONE Business Suite**.

## Download & Installation
Clients automatically receive update notifications and can update directly via:
**Settings** -> **Software Updates** -> **Check for Updates** -> **Download & Install**.

Standalone Windows setup installers (`.exe`), differential update blockmaps (`.blockmap`), and release manifests (`latest.yml`) are available under [Releases](../../releases).
